================================================================================
  妹居物语 自由模组 (MeijuMod v2.9.2) — 使用说明
================================================================================

【模组文件】
  install-hooks.js     注入钩子（挂载到 Electron 主进程）
  meiju-mod\
    mod.js             模组主体（所有补丁逻辑）
    mod.css            样式文件
    mod-config.json    默认配置模板

================================================================================
  一、安装方法
================================================================================

  1. 找到游戏根目录：
     Steam 右键「妹居物语」→ 管理 → 浏览本地文件
     通常位于：
     C:\Program Files (x86)\Steam\steamapps\common\MeijuStory_Demo

  2. 进入 resources 文件夹

  3. 将以下 2 项复制到 resources 目录下：
     - install-hooks.js         （放在 resources\ 根目录）
     - meiju-mod\ 整个文件夹     （放在 resources\meiju-mod\）

     结构如下：
     resources\
       app.asar
       install-hooks.js       ← 复制到这里
       meiju-mod\
         mod.js               ← 复制到这里
         mod.css
         mod-config.json

  4. 启动游戏即可，模组自动加载

================================================================================
  三、三套独立 API 配置
================================================================================

  搜题/场景 API      → 教师服拍照搜题 + 实景约会场景识别
  桌宠聊天 API       → 桌面宠物主动搭话 + 聊天窗口对话
  RTC 语音 API       → 火山引擎豆包全模态语音

  每套 API 独立填写 Base URL / Model / API Key，互不影响。
  游戏原版聊天 API（云端大模型设置）不受模组影响，各走各的。

  支持任意 OpenAI 兼容服务商，例如：
    - OpenAI        https://api.openai.com/v1
    - DeepSeek      https://api.deepseek.com/v1
    - Groq          https://api.groq.com/openai/v1
    - OpenRouter    https://openrouter.ai/api/v1
    - SiliconFlow   https://api.siliconflow.cn/v1
    - 自定义服务商   填写你的 Base URL

================================================================================
  四、桌宠按钮说明
================================================================================

  鼠标靠近或拖动桌宠窗口时，底部出现控制按钮：

  [🤖]  [💬]  [🎙]   [↔]  [✕]
   ①     ②     ③      ④    ⑤

  ① 全模态AI语音（原版）  — 多模态语音交互
  ② 独立聊天按钮（模组）  — 打开独立聊天窗口，使用桌宠聊天API
  ③ RTC语音按钮（模组）   — 火山引擎RTC语音输入，使用RTC配置
  ④ 大小切换             — 三档缩放 (100/200/300)
  ⑤ 关闭桌宠

================================================================================
  五、教师服搜题
================================================================================

  1. 教师服（outfit15）已自动解锁，无需购买
  2. 装备教师服后，聊天框出现相机图标 📷
  3. 点击相机 → 拍照或选图 → 裁切 → 自动调用搜题 API
  4. 识别结果以消息形式插入聊天

================================================================================
  六、RTC 语音开通（详见 .docx 文档）
================================================================================

  1. 注册火山引擎控制台 (https://console.volcengine.com)
  2. 开通「豆包大模型」→「实时语音通话」
  3. 创建应用获取 App ID 和 App Key
  4. 在模组面板 RTC 语音配置中填入
  5. 点击「测试连接」验证
  6. 开启开关后桌宠出现 RTC 语音按钮

  详细步骤见：方案三：豆包RTC桥火山引擎开通指南.docx

================================================================================
  七、配置存储位置
================================================================================

  所有配置保存在浏览器 localStorage 中：
    meiju_mod_config       模组开关状态
    meiju_mod_api_config   搜题/场景 API
    meiju_mod_pet_api_config  桌宠聊天 API
    meiju_mod_rtc_config   RTC 语音配置

  游戏原版聊天 API（IndexedDB 中的 APIKeyStorage）不受影响。

================================================================================
  八、卸载方法
================================================================================

  删除 resources\ 下这两个文件/文件夹即可恢复原版：
    - install-hooks.js
    - meiju-mod\
