# MeijuMod — 妹居物语 自由模组

即放即用模组，为《妹居物语》(MeijuStory) 解锁免登录桌面宠物、实景约会、AI 搜题等完整功能。

## 安装

将以下文件复制到游戏 esources\ 目录：

`
resources\
├── install-hooks.js       ← 放这里
└── meiju-mod\
    ├── mod.js
    ├── mod.css
    └── mod-config.json
`

启动游戏即可，模组自动注入。

## 功能

- **免登录** — 跳过账号登录直接进入游戏
- **桌宠破解** — 免登录桌面宠物 + 独立聊天按钮 + 独立API
- **AI搜题** — 教师服拍照搜题，使用自定义 AI 服务商
- **场景识别** — 实景约会场景分析，使用自定义 AI
- **RTC语音** — 火山引擎豆包全模态语音（需开通）

## 配置

游戏内 → 设置 → 云端大模型 → 左侧「模组」标签页

三套独立 API 配置：搜题/场景、桌宠聊天、RTC 语音。支持任意 OpenAI 兼容服务商。

## 兼容

- 不修改游戏原文件，删除即卸载
